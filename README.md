## Selected Projects

### [Course Options — Educational PWA](https://courseoptions.com/)

A platform for searching courses, institutions, and scholarships.

- Built PWA features for offline use, real-time notifications, and social login; the platform serves 15,000+ users.
- Reached a Lighthouse Performance score of **96/100**. Next.js SSR and Redis caching reduced server response time by **40%**.
- Reduced bounce rate by **25%** by simplifying OAuth login and improving search relevance.

**Tech:** Next.js, TypeScript, Node.js, MongoDB, Redis, PWA

### [RechnungsLens — Invoice Review App](https://rechnungs-lens-tawny.vercel.app/)

A student project for reviewing incoming invoices with synthetic data.

- Parses structured XRechnung/ZUGFeRD XML directly and uses Gemini extraction for scanned invoices and PDFs.
- Applies deterministic validation and routes each invoice to Release, Review, or Reject.

**Tech:** Next.js, TypeScript, Tailwind CSS, Gemini API, fast-xml-parser, pdf-lib  
[Source code](https://github.com/AliyanRizwanDev/RechnungsLens)

### [ERP Teacher Portal — Demo](https://erp-teacher-portal-five.vercel.app/)

A role-based teacher portal demo for timetables, class lists, student records, profiles, and leave or loan requests.

- Added data tables, dynamic forms, and filters, with shared UI state managed through Redux Toolkit.
- Created reusable components and role-based navigation.

**Tech:** React, TypeScript, Vite, Redux Toolkit, React Router, Tailwind CSS
